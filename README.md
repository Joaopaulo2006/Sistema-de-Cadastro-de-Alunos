# Sistema de Cadastro de Alunos

Projeto desenvolvido em Java para praticar conceitos básicos de programação.

## Funcionalidades

- Cadastro de alunos
- Listagem de alunos
- Busca por nome
- Remoção de alunos
- Cálculo de média
- Verificação de aprovação

## Conceitos utilizados

- Java
- Scanner
- ArrayList
- Classes e objetos
- Métodos
- Encapsulamento
- Estruturas condicionais
- Estruturas de repetição
- Switch/Case
- Construtores

## Como executar

Compile os arquivos:

```bash
javac src/*.java
```
